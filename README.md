# PlotWise Global

Professional real estate platform for property buying, selling, and investment consulting.

## Tech Stack

- React 19 + TypeScript
- Vite (build tool)
- Tailwind CSS + Radix UI
- React Router v6
- React Hook Form + Zod

## Features

- 🏠 Property listings and search
- 📝 Blog with articles and insights
- 👥 Client testimonials
- 📞 Contact forms and inquiries
- 📱 Fully responsive design

## Setup

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Folder Structure

```
src/
├── components/     # Reusable UI components
├── pages/         # Page components
├── hooks/         # Custom hooks
├── lib/           # Utilities
├── data/          # Static data
└── assets/        # Images and fonts
```

## Development

The project uses static data for blog posts and testimonials. All data is located in `/src/data/staticData.js`.
